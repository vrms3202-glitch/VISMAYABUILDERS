VISMAYA BUILDERS WEBSITE

Files:
- index.html   Main website page
- styles.css   All styling and responsive layout
- script.js    Mobile navigation, date validation and WhatsApp appointment form
- assets/      Local SVG image assets used by the website

HOW TO USE
1. Extract the ZIP file.
2. Keep the assets folder beside index.html, styles.css and script.js.
3. Open index.html in a browser, or upload the complete folder to your web host.

IMPORTANT
- The appointment form opens WhatsApp to +91 98466 19455 with the submitted details.
- A WhatsApp message is not sent automatically; the visitor must press Send.
- The email address field is optional because no business email address was supplied.
- The gallery artwork is illustrative, not a record of completed client projects.
- Google Fonts are optional; the site uses fallback fonts if they are unavailable.
